Caveman-Lite, in pictures

Caveman-Lite is a drop-in replacement for the OpenAI API that sits between AI agents and the model providers they pay for. For every request it decides whether a model is needed at all, answers repeats from cache, and sends the rest to the cheapest model that can handle it.

The real-world problem, and how it's solved

Teams running many agents pay for the same answers over and over, and one bad provider or hostile prompt can break everything. Each problem maps to one mechanism in the gateway.

What happens when an agent sends a prompt

Every request walks the same pipeline. Most of them are answered before a model is ever called; only a cold, safe, unique prompt reaches a provider.

Fifty agents, one upstream call

When identical requests arrive together, the first one opens a "flight" and the rest join it instead of calling the model again. They all still stream, by replaying the leader's token buffer.

Why a close match is not always a cache hit

Two questions about different companies look almost identical to an embedding model. The entity guard checks names, numbers and negations before it trusts a semantic match.

Failing over before the client notices

Each provider has its own circuit breaker. After repeated failures it stops sending traffic there, tests it again after 30 seconds, and routes requests to a healthy provider in the meantime.

One engine, three ways to run it

The public API, the in-browser command center and the burst simulator all run the same modules. Without API keys, a deterministic simulator stands in for the providers, so the demo never breaks.
